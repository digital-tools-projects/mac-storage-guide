# Mac Storage Guide: Find and Manage Disk Space

Running out of storage on a Mac can affect everyday tasks, downloads, application updates and overall performance.

This guide explains practical ways to understand disk usage and identify files that may be taking up unnecessary space.

## 1. Check Your Mac's Storage

Start by opening **System Settings → General → Storage**. Review the available storage and the categories using the most disk space.

## 2. Find Large Files

Large videos, archives, installers and exported projects can consume significant storage. Review your Downloads, Documents and media folders before removing anything.

## 3. Review Duplicate Files

Look for duplicate downloads, repeated exports and unnecessary copies. Confirm that important originals are backed up before deleting duplicates.

## 4. Review Application Data and Caches

Applications may store temporary data and cached files. Avoid manually deleting unfamiliar system files or folders.

## 5. Check Old Backups

Review old device backups and files you no longer need. Keep a separate backup of important information before removing anything.

## 6. Review Photos and Videos

Large photo libraries and video projects can occupy substantial disk space. Consider organising files and moving older media to suitable external storage.

## 7. Explore Mac Storage Management

If you want a dedicated tool to help review Mac disk usage and storage cleanup options, explore the [Mac disk space cleaner](https://mymacstorage.com/en-GB/mac-disk-space-cleaner).

## Final Checklist

- Check available disk space.
- Identify large files.
- Review duplicate downloads.
- Examine application storage.
- Check old backups.
- Organise photos and videos.
- Back up important files before deleting them.
